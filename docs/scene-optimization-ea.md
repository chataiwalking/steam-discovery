## 使用的四项 Skill

已完整阅读并按项目已有 React Three Fiber 架构应用：

- `threejs-animation`：程序化运动按现有 `useExperimentMotion` 进度驱动；直接修改 `ref`、实例矩阵与 uniforms；终态保持；悬挂雕塑用长度相关的摆动节奏与衰减。
- `threejs-interaction`：由 R3F 射线拾取处理真实部件的 hover/click；悬停显示部件说明，点击固定，再次点击收起；马赛克以 `instanceId` 选择具体拼片并显示位置与金色边框。
- `threejs-shaders`：材质保留 Three.js 标准光照，使用 `onBeforeCompile` 加入压缩传力、陶土纹理、水流纹理、陶瓷边缘与颗粒；色轮用三色均值与转速相关视觉混合；路径 shader 沿曲线提供流向、渐亮轨迹与定向脉冲。
- `threejs-postprocessing`：所有场景接入主 Agent 的公共 composer/OutputPass/FXAA 管线，不创建每课的额外全屏 pass。局部 shader 输出兼容 Three.js 的 tone mapping 与 color space chunks；绝大多数说明颜色保持普通亮度，避免把承重结构做成发光物。

## 共用实现与资源约束

- 新增 `EngineeringArtEffects.tsx`，只供上述工程/艺术组件使用；包含 `InspectPart`、`FlowPath`、`ForceArrow`、`StudyMaterial`、`ColorMixDisk`、`BeatPulse`。
- 帧回调只更新对象 transform、shader uniform 与 `InstancedMesh` 矩阵；没有每帧 `setState`。
- 检查标签由 pointer 事件控制；固定说明不产生学习完成证据，也不代替按钮启动的实验。
- 自建 `TubeGeometry`、`ExtrudeGeometry`、`LatheGeometry`、`ShapeGeometry`、shader/标准 material 在 effect cleanup 中释放。
- 马赛克主体为一次实例化绘制，静止进度时不重新写实例矩阵；检查边框额外最多一张 mesh。
- 路径使用少量窄 tube，每条一张 mesh；没有添加粒子云、景深、全屏噪声或每课独立 composer。
- `useExperimentMotion` 的 2.5 秒观察、暂停/示范时间、runId 完成去重保持原合同；未改 App、任务判断、参数、测试定位、课程 JSON 或 audio 文案。
