# 首页标识与展台重构

首页原有六个大课程标签和顶部/底部文字块覆盖了实验装置。现在展台只保留24px编号圆点，课程名称、选择入口和动态说明放到画面外，模型可以完整展示。

Logo采用原创双色探索指针与开放轨道；页眉和favicon共用核心轮廓，深色背景下以砂金与冰青保持识别。品牌文字改为更清楚的名称与简短中文副标。

## 交互与布局

- 六个编号保留44px触摸与键盘命中区域；点选装置或编号进入原课程。
- 展台下方保留六个具名入口，悬停/键盘焦点在下方显示简短课程说明。
- 去掉画面内的大课程卡、英文副标题和覆盖式提示；桌面与手机采用同一结构。
- WebGL不可用时，画面外的具名课程入口仍可进入课程。

## 验证

TypeScript/Vite构建通过。Chrome检查覆盖1026×824、1440×1100、390×844三种视口：无横向溢出、六个编号与六个具名入口、键盘说明、六课跳转、品牌返回首页及WebGL不可用时导航均通过。页内无JavaScript错误。截图及结果位于本轮output/playwright/home-brand-20261004。

课程数据、80课/240流程/720音频的内容合同保持原值。生产资源摘要、服务器激活和GitHub来源提交分别回读。
