# 科学与技术扩展场景优化

范围为 `ScienceExperiments.tsx` 的 8 课和 `TechnologyExperiments.tsx` 的 9 课，共 17 课。原来的昼夜、水循环和齿轮等基础场景由主任务的另一部分处理。课程参数、选项、讲解目标、测试定位与完成回调均未改动。

## 四项 Skill 的落地

- `threejs-animation`：以现有 `useExperimentMotion` 的 progress 驱动所有教学动画，用 smoothstep 改善启动与收尾。暂停时 progress 冻结；讲解示范由 narrationTime 决定；实验完成仍由原公共 hook 在 2.5 秒报告。
- `threejs-interaction`：17 课均通过 React Three Fiber 的对象 raycasting 提供 hover 光环、指针反馈和点击原理解说。点击原理不改变实验参数和完成证据。
- `threejs-shaders`：`ScienceTechnologyEffects.tsx` 提供 TubeGeometry UV 路径脉冲、液面顶点扰动与径向波纹 fragment shader；GLSL 的 phase、strength、frequency 来自实验进度和课程参数。轨道、光水能量、电流、编码、风与感应控制使用各自的因果条件。
- `threejs-postprocessing`：发光只用于光源、能量、路径、位权等教学线索，使用受控的 `toneMapped=false` 与 emissive 供主任务的公共 EffectComposer、bloom 与 OutputPass 正确输出。此模块没有建立第二套 composer，也没有模糊正文或整个实验台。

## 逐课改动、依据与边界

| 课程 | 可辨识的改动 | 科学依据与限制 |
| --- | --- | --- |
| 月亮的脸 `moon-phases` | 改善受光区/明暗分界的曲面表现，顶视图增加由太阳方向入射的光路径。 | 月相来自从地球看到的受光比例；保留「不是地球的影子」说明。光线与球体大小为示意，不绘制日月食。 |
| 太阳系旅行 `solar-system` | 三条轨道加入各自色彩的 shader 行进标记，所选行星轨道更明确，速度与原三颗行星的公转比率对应。 | 行星绕日与不同周期保留；轨道半径、行星尺寸与时间压缩，未声称开普勒定量模拟。 |
| 磁铁的朋友 `magnetism` | 每块磁铁附近加入静态曲线磁场提示；距离更近时提示更清楚，与原吸斥位移共同反馈。 | 同极相斥、异极相吸；明确提示为「单磁铁周围」的非定量磁场示意，未把两块磁铁叠加场画成求解结果，曲线也不是粒子。 |
| 沉下去还是浮起来 `floating` | 每块物体入水时产生有限持续的径向扰动；补充浮力与重力的不同色箭头。 | 平均密度决定沉浮；箭头为稳定结果的受力关系提示，不是瞬时受力数值；同体积不同材料的原结果保留。钢块稳定模型的浮力小于重力，漂浮材料的两个箭头等长。 |
| 种子的旅行 `plant-growth` | 将光照与水分显示为黄/蓝路径；缺光和缺水条件会关闭相应路径，生长快慢仍由时间控制。 | 光与水需要适量；路径说明输入条件，未把它当作叶片内部化学反应的数值计算。动画明确加快时间。 |
| 看得见的声音 `sound-waves` | 在原弦振动外增加 48 个空气粒子，粒子沿传播方向往返；快慢改变波长/振动次数，振幅单独改变位移。 | 空气中的声波是纵波；外扩环速度不再随音调改变，避免混淆音调与传播速度。空气粒子和环都是可视化模型，真实空气并非蓝色颗粒。 |
| 影子变变变 `shadows` | 增加两条直线光路；灯运动时光路起点准确跟随，不受观察相机旋转影响。 | 光从点源直线传播，实际投影仍由场景 pointLight/shadow 产生；引导光线只用来说明传播路径，不替代真实投影计算。 |
| 水的三种样子 `states-of-water` | 48 个点的粒子放大窗展示规则排列、相邻运动与分散运动；加热/冷却显示相反方向和不同色的能量路径。 | 分子视窗为结构关系示意，间距不按比例；加热程度不是温度计刻度，模型未计算相变潜热。保留「水蒸气不可见，白雾是小水滴」。无运行时放大窗与现有最终条件一致。 |
| 点亮小灯泡 `electric-circuit` | 将原来横向往返的单个亮点替换为沿完整回路前进的 shader 路径；断开时不显示通电路径，闭合运行后才亮起。 | 简单闭合回路才能导通；亮点表示电流路径，不表示电子的实际漂移速度，灯泡数量仍采用原装置示意。 |
| 会思考的红绿灯 `traffic-light` | 行人/车辆分别有许可路线；停止路线停在停止区，移动使用平滑启动与减速。 | 原车辆信号与行人信号互锁保留；等待参数仍控制行人何时开始走。绿灯路径是通行示意，不代替现实道路观察。 |
| 机器人走迷宫 `robot-path` | 起点到指令终点加入连续路线与方向性脉冲；路线终点准确随方向和步数改变。 | 每一步仍是原网格距离；未添加自动寻路或改变障碍规则。 |
| 阳光变电能 `solar-panel` | 面板改为固定倾角，太阳高度改变入射方向；发电/风扇与入射光在法线方向的余弦投影关联，背面不给出发电流。 | 原先面板始终跟随太阳却把太阳高度直接当作功率，因果关系不清。现在只展示受光几何关系；太阳距离压缩，不采用局部灯的平方反比，不是实际功率预测。 |
| 风的发电机 `wind-turbine` | 风箭头和 shader 路径改为穿过叶轮正面，与叶轮轴对齐；电能路径只在正常叶片运行时出现。 | 风推动叶轮、机械能转电能；锁定时仍有风、无转动与输出。等级影响示意速度，未宣称真实风机功率曲线。 |
| 净水小工厂 `water-filter` | 过滤过程加入水流路径与收集液面的波纹；说明粗/细颗粒是否停在过滤层，液面提示跟随容器填充高度。 | 依据孔径/材料拦截部分悬浮颗粒；原 16 个颗粒的保留/通过条件保持，未声称去除所有溶解污染物，保留不能直接饮用的说明。 |
| 远方的小消息 `telegraph` | shader 信号严格使用与发报键/接收灯相同的频率和占空比，长短信号同步出现与消失。 | 双方约定长短编码；仍是同步电路示意，未虚构长距离传播延迟，也未把长短脉冲标成完整摩斯文本。 |
| 零和一的秘密 `binary-code` | 在每一位前加入 4/2/1 个小计数块；位为 1 时亮起、位为 0 时灰色，与原灯/数字编码一起对应算式。 | 三位二进制表示 0—7，位权相加；计数块在运行时随所属位逐步揭示，表示的数与参数一致。 |
| 自动门的眼睛 `sensors` | 用扇形直线标记检测范围；人在范围内时才出现感应器到控制装置的信号路径。 | 必须同时满足「开启」和「人走入范围」；显式说明范围线不是所有传感器都会发出的可见光，不声称这是某一种特定红外/雷达器件。 |

## 资源与验证

路径使用有限的 TubeGeometry，shader 不创建逐帧对象；每个粒子窗只用一个 BufferGeometry 和一次 points draw，48 个点。所有自建 TubeGeometry、BufferGeometry 与已有声波 Line 的资源在卸载时 dispose。React 状态仅用于 hover/click；教学进度、粒子、光线与显隐直接更新 refs、GPU 属性和 uniforms。

编译验证：已运行 `npx tsc -b --pretty false`，通过。公共构建、课程回归、浏览器 shader 检查、公开域名与 GitHub 同步由主任务统一完成，不能从这里的编译结果推断发布完成。
