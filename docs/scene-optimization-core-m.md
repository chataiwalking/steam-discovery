# 核心课程、小岛与数学场景优化

## 范围与实际改动

覆盖原六课、九个数学扩展场景，以及小岛六个课程入口。只修改相应场景与本地 `MathCoreEffects.tsx`，保留课程文案、年龄轨道、按钮文本、任务证据及回调类型。数学的点选反馈是观察反馈，不产生 `experiment-complete`，原有动画完成依据仍由 `useExperimentMotion` 报告。

## 四个 Skill 的使用落点

- `threejs-animation`：delta 指数阻尼、smoothstep 进度、程序性跳跃/位移/转动、停止无效的暂停更新。
- `threejs-interaction`：基于 R3F raycast 事件的局部 hover/click；事件停止传播避免一击触发多个任务动作；cursor 在离开/卸载时清理；装饰网格的 raycast 为空。
- `threejs-shaders`：环形反馈、湖面波纹、Fresnel 大气边缘、柔和光束；动画只更新 uniforms/ref，不逐帧 setState。
- `threejs-postprocessing`：此范围没有新增全屏 pass；将透明装饰的 depthWrite 关闭，保持 shader 与主 Agent 的公共 EffectComposer/OutputPass 配合，避免各场景独立堆叠 composer。

## 时钟、资源与性能

- 数学动画仍消费共享 `useExperimentMotion`；讲解进度可直接定位，物体终点不依赖浏览器帧率。核心教学动画消费 `useSceneClock`，局部阻尼使用 delta。
- 选择环只在 hover 或短点击脉冲期间 visible；反馈不缩放物体真实几何尺寸。暂停时反馈脉冲时间停止，pointer over/out/click 显式 invalidate 并直接同步静态反馈，退出时清零点击反馈，避免 demand 模式不亮或残留。小岛入口选择环与抬起同样在暂停下直接响应输入。
- ShaderMaterial/Geometry 由 R3F 生命周期释放；原有 CanvasTexture、克隆水纹纹理、手工生成地形继续显式 dispose。地球 normalScale 使用 memo，避免重复创建 Vector2。
- 水循环粒子最多 20 个，复用一个 Object3D 更新实例矩阵，无每帧 React state，也不逐粒子新增灯光。波纹只叠加一个薄网格。
- 暂停仅冻结时间推进：暂停后主动转动地球、切换灯光、分类形状时，通过 layout effect 直接同步新的目标角度、光束强度或分类坐标并显式 invalidate，保证模型与 HUD/学习证据一致。仅切换到暂停状态、不修改参数时，保留当时动画姿态，不瞬间跳到目标。

## 本分工验证

- `npx tsc --noEmit --pretty false`：通过；完成第二轮检查后全部源文件类型有效。
- `git diff --check`：通过。
- 本分工没有运行新的独立测试或浏览器服务器；主 Agent 负责全项目 build、既有测试、浏览器/移动端 shader 编译与演示/暂停检查，以及部署与 GitHub 同步。
- 这里的视觉动画是教学示意，没有新增真实天气、桥梁力学或大气散射数值计算，原课程科学表述与任务合同保持原样。
